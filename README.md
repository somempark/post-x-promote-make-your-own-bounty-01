A small Node 22 program that validates the entry's X post link (POST.json) for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty and writes a deterministic summary to the output directory. The entry itself is one public X post from @kongtouhunter7 quoting make.fun's make-your-own-bounty post, with a photo attached — ranked by its replies, reposts and quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
